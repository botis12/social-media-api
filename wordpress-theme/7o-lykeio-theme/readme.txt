=== 7ο ΓΕΛ Ιλίου ===
Requires at least: 6.4
Requires PHP: 8.0
Version: 1.1.1

== Εγκατάσταση ==

1. Πίνακας Ελέγχου → Εμφάνιση → Θέματα → Προσθήκη → Μεταφόρτωση θέματος →
   επιλέξτε το 7o-lykeio-theme.zip → Εγκατάσταση → Ενεργοποίηση.
2. Τέλος. Με την ενεργοποίηση δημιουργούνται αυτόματα:
   - οι μόνιμοι σύνδεσμοι (/%postname%/) και οι κανόνες των διευθύνσεων,
   - οι σελίδες: Το σχολείο μας, Σύλλογος Διδασκόντων, Μαθητές & Γονείς,
     Επικοινωνία, Δήλωση Προσβασιμότητας,
   - οι κατηγορίες ανακοινώσεων, είδη δράσης, κατηγορίες εγγράφων, σχολικά έτη,
   - τα 4 μενού (κύριο + 3 του υποσέλιδου),
   - το λογότυπο και το περιεχόμενο: 8 ανακοινώσεις, 7 δραστηριότητες,
     8 έγγραφα, 9 φωτογραφίες (μόνο αν ο ιστότοπος δεν έχει ήδη ανακοινώσεις).

Αν κάτι λείπει: Εμφάνιση → Εγκατάσταση θέματος → «Εκτέλεση εγκατάστασης».
Δεν δημιουργείται τίποτα διπλό.

ΣΗΜΑΝΤΙΚΟ: τα PDF των εγγράφων είναι δείγματα. Αντικαταστήστε τα από
Έγγραφα → (έγγραφο) → «Επιλογή / μεταφόρτωση αρχείου».

== Διευθύνσεις ==

/anakoinoseis/     Ανακοινώσεις   (/kathgoria/<κατηγορία>/)
/zoi-scholeiou/    Δραστηριότητες (/eidos-drasis/<είδος>/)
/eggrafa/          Έγγραφα        (/eggrafa/?eidos=…&etos=…)
/stigmiotypa/      Φωτογραφίες

== Πού αλλάζει τι ==

- Τηλέφωνα, email, ωράριο, κείμενα και εικόνες αρχικής, γρήγορη πρόσβαση:
  Εμφάνιση → Προσαρμογή → 7ο ΓΕΛ Ιλίου
- Λογότυπο, όνομα: Εμφάνιση → Προσαρμογή → Ταυτότητα ιστότοπου
- Μενού: Εμφάνιση → Μενού
- Επείγον / προθεσμία / συνημμένα: στο πλάι και κάτω από κάθε ανακοίνωση
- Ημερομηνία και τόπος δράσης: στο πλάι κάθε δραστηριότητας

== Αν βλέπετε 404 στις εσωτερικές σελίδες ==

Ρυθμίσεις → Μόνιμοι σύνδεσμοι → Αποθήκευση. Σε Apache πρέπει να είναι
ενεργό το mod_rewrite και να επιτρέπεται η εγγραφή του .htaccess.
