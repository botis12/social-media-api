# 🧾 Μοιρασιά

Μια μικρή full-stack εφαρμογή που λύνει ένα πραγματικό πρόβλημα: **μετά από ένα ταξίδι,
ένα δείπνο ή ένα σπίτι με συγκάτοικους, ποιος χρωστάει σε ποιον;**

Γράφεις ποιος πλήρωσε τι, και η εφαρμογή σου λέει τις **λιγότερες δυνατές πληρωμές**
για να μηδενίσουν όλοι. Χωρίς λογαριασμό, χωρίς εγγραφή — μόνο ένας κωδικός 6
χαρακτήρων που μοιράζεσαι με την παρέα.

*A tiny full-stack app for splitting shared expenses: enter who paid what, get the
minimum set of payments that settles everyone up. No accounts — just a 6-character
group code you share.*

---

## Εκκίνηση

Χρειάζεται μόνο **Node.js 22.5+**. Καμία εξάρτηση, κανένα `npm install`.

```bash
cd moirasia
npm start           # → http://localhost:3000
npm test            # 19 tests
```

Ρυθμίσεις μέσω μεταβλητών περιβάλλοντος:

| Μεταβλητή | Προεπιλογή | Τι κάνει |
|---|---|---|
| `PORT` | `3000` | Θύρα του διακομιστή |
| `DB_FILE` | `./data/moirasia.db` | Αρχείο SQLite |

## Πώς δουλεύει

1. **Νέα παρέα** — δίνεις όνομα και τα άτομα. Παίρνεις κωδικό, π.χ. `K7M2QX`.
2. **Έξοδα** — τι, πόσο, ποιος πλήρωσε και για ποιους (μπορεί να μην αφορά όλους).
3. **Ξεκαθάρισμα** — η εφαρμογή δείχνει ποιος δίνει σε ποιον και πόσο.
4. **Μοιράζεσαι** τον σύνδεσμο `/<ΚΩΔΙΚΟΣ>` και ο καθένας προσθέτει τα δικά του έξοδα.

### Η λογική πίσω από το ξεκαθάρισμα

- Όλα τα ποσά κρατιούνται σε **ακέραια λεπτά**, οπότε δεν χάνεται ποτέ ούτε ένα σεντ
  σε στρογγυλοποίηση. Τα λεπτά που περισσεύουν σε μια διαίρεση (π.χ. 10,00 € στα 3)
  μοιράζονται ένα-ένα, ώστε το άθροισμα να βγαίνει ακριβώς.
- Για κάθε άτομο υπολογίζεται το **υπόλοιπο**: όσα πλήρωσε μείον όσα κατανάλωσε.
  Το άθροισμα όλων των υπολοίπων είναι πάντα μηδέν.
- Το ξεκαθάρισμα είναι **greedy**: ο μεγαλύτερος οφειλέτης πληρώνει τον μεγαλύτερο
  πιστωτή. Κάθε πληρωμή μηδενίζει τουλάχιστον ένα άτομο, άρα χρειάζονται το πολύ
  `άτομα − 1` πληρωμές, αντί για ο καθένας στον καθένα.

## Δομή

```
moirasia/
├── server/
│   ├── index.js   # HTTP server: routing, static αρχεία, χειρισμός σφαλμάτων
│   ├── api.js     # έλεγχοι εγκυρότητας + read model της παρέας
│   ├── db.js      # SQLite (node:sqlite), σχήμα και queries
│   └── split.js   # καθαρή λογική: μοιρασιά, υπόλοιπα, ξεκαθάρισμα
├── public/        # frontend χωρίς build step: index.html, app.js, styles.css
└── test/          # node:test — 9 unit + 10 API tests
```

Backend: Node.js (`node:http` + `node:sqlite`), μηδέν εξαρτήσεις.
Frontend: ένα HTML αρχείο με vanilla JavaScript — δουλεύει σε κινητό, σε
υπολογιστή, σε light και dark theme.

## API

Όλες οι απαντήσεις επιστρέφουν ολόκληρη την κατάσταση της παρέας (μέλη, έξοδα,
υπόλοιπα, ξεκαθάρισμα), οπότε το frontend δεν χρειάζεται δεύτερη κλήση.

| Method | Endpoint | Τι κάνει |
|---|---|---|
| `GET` | `/api/health` | Έλεγχος ζωής |
| `POST` | `/api/groups` | Νέα παρέα — `{ name, members: [...] }` |
| `GET` | `/api/groups/:code` | Η κατάσταση της παρέας |
| `POST` | `/api/groups/:code/members` | Προσθήκη ατόμου — `{ name }` |
| `POST` | `/api/groups/:code/expenses` | Νέο έξοδο — `{ description, amount, payerId, participantIds? }` |
| `DELETE` | `/api/groups/:code/expenses/:id` | Διαγραφή εξόδου |

Το `amount` δέχεται και `"12,50"` και `12.5`. Αν λείπει το `participantIds`, το
έξοδο μοιράζεται σε όλη την παρέα.

```bash
curl -X POST localhost:3000/api/groups \
  -H 'content-type: application/json' \
  -d '{"name":"Νάξος","members":["Άννα","Βασίλης","Γιώργος"]}'
```

## Σημειώσεις

- Ο κωδικός της παρέας είναι το «κλειδί»: όποιος τον έχει, βλέπει και γράφει.
  Είναι σκόπιμο (μηδενική τριβή για την παρέα), αλλά μη βάζεις εκεί ευαίσθητα δεδομένα.
- Τα δεδομένα ζουν σε ένα αρχείο SQLite· κράτα αντίγραφο του `data/moirasia.db`
  αν σε ενδιαφέρει το ιστορικό.
